# Implementation contract
Backend package app in backend/. API /api/v1. JSON records use id strings. Frontend port 5173 proxies /api to backend:8000. Bearer session token; login POST /auth/login {email,password} => {token,user:{id,email,role}}. GET /auth/me. First admin created by CLI, never public credentials.
GET /analytics => {accounts,identities,non_human_identities,high_risk_identities,resources,attack_paths,critical_findings,alerts,scans,trend:[{date,score}],...}. GET list endpoints /accounts /scans /identities /policies /resources /findings /events /alerts /incidents /users => {items:[],total:number}, query q,limit,offset. GET /graph => {nodes:[{id,label,type,...}],edges:[{id,source,target,type,confidence,evidence,assumptions}]}; GET /attack-paths => {items:[],total}. POST /scans {mode:"demo",account_id?:str} -> scan. POST /events/import {Records:[CloudTrail records]} => results. POST /policies/analyze {policy:object,action:string,resource:string,context?:object} => decision. POST /remediation {identity_id:string,policy:object} => before/after paths and risks. PATCH /findings/{id} {status,assignee?,note?}. POST /incidents {title,description,finding_ids:[]} PATCH /incidents/{id} {status?,note?}. GET /reports?format=json|pdf. GET/PATCH /settings. POST /accounts {name,profile?,role_arn?,region?,expected_account_id?}. POST /users {email,password,role}. GET /audit. GET /health. SSE /scans/{id}/stream via fetch Authorization.
Engine app/engine.py interface: demo_dataset() -> dict with accounts,identities,resources,events. Identity {id,name,type,account_id,policies:[policy documents],trust_policy?,boundary?,...}; resource {id,name,type,account_id,sensitive,...}. analyze(dataset)->{nodes,edges,paths,findings,alerts,identities,resources,...}. evaluate(policy, action, resource, context=None, **kwargs)->dict decision/evidence/assumptions. detect_events(events)->list alerts. Findings include id,title,severity,score,confidence,identity_id,evidence,remediation,status. Engine outputs JSON serializable. app/aws.py collect(profile=None,role_arn=None,region="us-east-1",expected_account_id=None)->dataset including errors (partial visibility explicit).
Backend agent owns API models DB migrations requirements backend/tests/test_api.py. Engine agent owns engine.py fixtures test_engine.py and docs IAM_ANALYSIS.md ATTACK_PATH_ENGINE.md CLOUDTRAIL_DETECTION.md EVALUATION.md plus evaluation script. Frontend agent owns frontend exclusively. Root owns aws.py infrastructure docs integration.
